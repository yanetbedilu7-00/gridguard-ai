## Overview

GRIDGUARD AI is an intelligent grid management system that detects abnormal energy conditions, predicts instability, prioritizes critical infrastructure, and simulates safer responses before intervention.

### Key Features

- **Predictive Risk Engine** - Real-time anomaly detection with 91%+ confidence
- **Autonomous Protection** - Automatically prioritizes critical infrastructure
- **Resilience Simulation** - Test interventions before execution
- **WebSocket Realtime** - Live data streaming via Socket.IO
- **REST API** - Full backend API for data integration
- **Data Persistence** - JSON storage with historical data
- **Professional UI** - Clean white/brown theme
- **Keyboard Shortcuts** - Quick scenario switching (1-6)
