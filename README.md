# GRIDGUARD AI
## Autonomous Grid Resilience System

### Problem
Power grid failures cost billions annually and threaten lives during extreme weather events. Current monitoring systems only detect failures after they occur. GRIDGUARD predicts and prevents failures before they happen.

### Solution
GRIDGUARD AI is an intelligent grid management system that:
- Monitors voltage, current, temperature in real-time
- Predicts failure probability using risk engine
- Prioritizes critical infrastructure (hospitals, emergency services)
- Simulates interventions before execution
- Reduces risk scores instantly

### Features
- Real-time dashboard with live data visualization
- Predictive risk engine with confidence scoring
- Autonomous agent for decision making
- Resilience simulation for safe interventions
- Critical infrastructure protection
- Keyboard shortcuts for instant scenario testing

### Quick Start
1. Open `index.html` in any modern browser
2. Watch live grid data update automatically
3. Press keys to test scenarios:
   - `1` = Overheat scenario
   - `2` = Overload scenario
   - `3` = Voltage drop scenario
   - `4` = Reset to normal
   - `5` = Run autonomous agent
   - `6` = Run resilience simulation
